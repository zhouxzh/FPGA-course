# 酱味大鸡

基于 ZYNQ 的 FPGA 图像处理系统 — Sobel 边缘检测及扩展算法

实验课题：sobel_05_pc_control_display + 综合扩展任务 3

## 实验五原始成果

核心目标：上位机统一调度下，实现灰度化转换、Sobel 边缘提取、彩色叠加的完整流程。

资源占用：Slice LUTs=2009, Slice Registers=1515, BRAM=4, DSP=0。设计非常节省资源，为后续扩展留充足空间。

时序分析：100MHz 时钟，全部路径满足建立与保持时间约束，WNS=0.000ns，无时序违例。

## 扩展任务：三核并行处理架构

Sobel、Prewitt、Sharpen 三个计算核心并行工作，共享灰度图和 3×3 滑动窗口。

BRAM 控制字：0x9000=display_mode (0=原图/1=灰度/2=边缘/3=叠加/4=锐化)，0x9004=threshold，0x9008=overlay_en，0x900C=algorithm_sel (0=Sobel/1=Prewitt)

### 三种算法对比

| 维度 | Sobel | Prewitt | Sharpen (USM) |
| --- | --- | --- | --- |
| 原理 | 有加权，抗噪强 | 平等权重，边缘锐利 | 原图减模糊图，增强细节 |
| 梯度公式 | gx 含乘2操作 | gx 无乘2操作 | 无梯度计算 |
| 输出 | 黑白边缘图 | 黑白边缘图 | 增强细节灰度图 |
| 资源特点 | 用移位代替乘2 | 节省 LUT 硬件资源 | 均值近似代替除法 |

## 仿真验证

策略：1) Python 写像素级精确模型；2) 100% 比对 FPGA 代码输出与标准答案；3) 验证命令解析、模式切换、阈值传递等所有逻辑。

## 实验结果

六模式效果对比：Original / Gray / Sobel Edge / Prewitt Edge / Sobel Overlay / Prewitt Overlay。量化差异：Sobel 抗噪性更强，Prewitt 边缘定位更精准锐利。

锐化效果：增强图像高频细节，让画面更清晰有质感。Sobel 比 Prewitt 多 22.9% 边缘点。

## 遇到的问题

1. Prewitt 和 Sobel 视觉效果接近 → 量化分析发现 Sobel 多 22.9% 边缘点
2. 除法运算太占资源 → 乘法和移位近似代替
3. PC 端程序报错 → 数据溢出，改用更大范围整数类型
4. 模式切换失灵 → 控制信号位宽不够，2-bit 改 3-bit

## 扩展前后对比

| 指标 | 修改前 (仅 Sobel) | 修改后 (三核并行) |
| --- | --- | --- |
| Slice LUTs | 2,009 | ~3,500-4,000 |
| Slice Registers | 1,515 | ~2,800-3,200 |
| DSP | 0 | 0 |
| 时序 | WNS=0.000ns | WNS=0.75ns |

增加两个算法后资源总量翻倍，但总占用率仍 <10%，余量充足。新增算法未引入关键路径延迟。

## 总结

已实现：上位机 UART 实时控制、多种边缘检测算法切换、图像锐化独立运行、彩色边缘叠加与阈值调节、三核并行低资源占用。

未来方向：引入 Canny 边缘检测、1080P 升级、视频流实时处理。
