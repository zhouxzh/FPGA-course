# 这里开发板已经不耐烦了

基于 Zynq 的实时图像处理系统拓展 — 高斯滤波、中值滤波、二值化算法硬件实现与全流程验证

## 任务背景与目标

基于 sobel_05_pc_control_display 工程拓展，原工程仅支持灰度转换和 Sobel 边缘检测，算法库单一。本次对标课程综合拓展最高等级要求：

- 算法能力扩充：新增 3×3 高斯滤波、中值滤波、阈值二值化三类经典图像预处理算法
- 上位机实时交互：UART 串口通信，PC 下发单字符指令，毫秒级切换算法输出
- 多层级验证闭环：RTL 功能仿真 → Python 软件模型对标 → 开发板硬件上板

## 算法选择与设计

高斯滤波 (线性平滑降噪)：3×3 归一化高斯核加权卷积，抑制高斯热噪声。软件浮点运算，硬件定点整数移位除法，适配 FPGA 无浮点单元特性。

中值滤波 (非线性脉冲噪声抑制)：3×3 窗口内 9 个像素冒泡排序取中间值，针对椒盐噪点、画面坏点有极强滤除效果，解决线性滤波边缘模糊缺陷。

二值化 (灰度图像分割)：设定固定阈值，灰度映射为纯黑(0)/纯白(255)二值图像，降低数据位宽，简化后续特征提取。

模块化设计：各算法独立封装为 Verilog 子模块，并行接收同源数据流。UART 指令驱动 MUX 选通算法结果，模块解耦，可扩展性强。

## 系统整体设计

数据通路：PC 图像/控制 → UART → ZYNQ PS → AXI BRAM → PL → HDMI。

指令控制：UART 单字符指令 → MUX 选通对应算法通路 → HDMI 输出。
- '0' → 原图, '1' → Sobel, '2' → 高斯滤波, '3' → 中值滤波, '4' → 二值化

## 关键代码实现

高斯滤波模块：3×3 加权模板 (1-2-1/2-4-2/1-2-1)，全定点整数运算，行缓存流水线保证像素连续输出。

中值滤波模块：3×3 窗口 9 像素冒泡排序取中值，组合逻辑并行排序，单周期完成。

二值化模块：`pixel_out = (pixel_in > threshold) ? 8'd255 : 8'd0;`，简单阈值比较。

## 实验结果

RTL 仿真验证：全流程信号无丢包、无逻辑冲突，功能覆盖率 100%。

软硬件模型对比（原图/灰度/高斯/中值/Sobel/二值/边缘叠加）：FPGA 硬件输出与 Python Golden Reference 视觉上完全重合。中值滤波保留物体边缘不模糊，高斯滤波对画面整体平滑降噪。二值化极大降低图像数据量。

算法效果对比：
- 原始图像：保留完整色彩层次与细节
- Sobel：精准捕捉物体边缘轮廓
- 高斯滤波：加权平均平滑降噪，柔和边缘过渡
- 中值滤波：滤除椒盐噪点，保持边缘信息
- 二值化：黑白二元输出，最大化对比度

## 遇到的问题与解决方法

| 问题 | 成因 | 解决方案 |
| --- | --- | --- |
| DRC 端口报错 | 新增 PL 端口未在 xdc 约束 | 查阅原理图，补充引脚与电平约束 |
| 图像横向条纹/色彩失真 | Verilog 数据位宽不匹配/时序逻辑错误 | RTL 仿真逐周期分析波形，修正代码 |
| UART 通信不稳定 | 波特率不一致/串口线接触不良 | 统一 115200，更换串口线 |
