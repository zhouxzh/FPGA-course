# 我从山中来

上位机控制显示 (sobel_05_pc_control_display) — FPGA 课程设计

## 系统架构总图

PC 端 → UART 115200 → ZYNQ PS (Cortex-A9) → AXI BRAM → ZYNQ PL (图像处理) → HDMI 1280×720

PS 端：XUartPs 初始化 115200 8N1；轮询检测帧同步头 55 AA (图像) / A5 5A (控制)；图像帧解析 RGB888 → 逐像素写入 BRAM；控制帧解析 cmd/value → 写入控制寄存器 (BASE+0x9000~0x9008)

PL 端：每 HDMI 帧扫描 BRAM 128×72 → rgb_to_gray → 5 个算法核并行运算 → 写入各自缓存；显示输出读取控制字 → MUX 选择模式 → 阈值判断/彩色叠加 → TMDS 编码 → HDMI

缩放：SCALE_X = 1280/128 = 10, SCALE_Y = 720/72 = 10

## 控制协议设计

图像帧协议 (同步头 55 AA)：帧头 55 AA width height 18，行头 33 CC row，像素 RGB 每行 128×3=384 字节，总帧长约 27943 字节，115200 baud ≈ 2.4 秒/帧

控制帧协议 (同步头 A5 5A)：格式 A5 5A cmd value (仅 4 字节)

- cmd=01 显示模式：0=原图 1=灰度 2=Sobel 3=彩色叠加 4=腐蚀 5=膨胀 6=均值滤波 7=高斯(预留) 8=锐化
- cmd=02 Sobel 阈值：0~255 (默认 80)
- cmd=03 彩色叠加：0=关闭 1=打开

## PS 端软件设计

main.c 流程：uart_init() → fill_test_pattern() → control_write_defaults() → wait_for_packet_start() 循环检测 55 AA (图像帧) / A5 5A (控制帧)

AXI BRAM 地址空间 (base=0x40000000)：
- 图像区 BASE+0x0000：128×72×4 = 36,864 字节，格式 0x00RRGGBB
- 控制字区：BASE+0x9000=display_mode[3:0]，BASE+0x9004=threshold[7:0]，BASE+0x9008=overlay_enable[0]

## PL 端硬件层次结构

hdmi_bram_sobel_display 内部例化：
- rgb_to_gray (灰度转换)
- sobel_core (边缘检测)
- erosion_core (腐蚀)
- dilation_core (膨胀)
- mean_filter_core (均值滤波)
- sharpen_core (锐化)

5 个算法核并行运算，共享同一 gray_valid 流。

## 算法模块一览

| 算法 | 核心公式 | 边界处理 |
| --- | --- | --- |
| Sobel | Gx=[-1,0,+1;-2,0,+2;-1,0,+1], Gy=[+1,+2,+1;0,0,0;-1,-2,-1], \|Gx\|+\|Gy\|→8bit | 黑色(0) |
| 腐蚀 | 3×3 邻域取最小值, min(p00..p22) | 黑色(0) |
| 膨胀 | 3×3 邻域取最大值, max(p00..p22) | 白色(255) |
| 均值滤波 | Avg = (Σ9像素 × 57) >> 9, 57/512 ≈ 1/9 | 白色(255) |
| 锐化 | Sharp = 5×Center − (上+下+左+右), 钳位 0~255 | 白色(255) |

## 显示模式控制

9 种显示模式 (display_mode 4-bit)：0=原图 1=灰度 2=Sobel 3=彩色叠加 4=腐蚀 5=膨胀 6=均值滤波 7=高斯(预留) 8=锐化

叠加优先级：if (mode≠2,4,5) && overlay_active && edge_on: RGB = (255,32,32) (红色边缘覆盖)

## 综合扩展对比

| 对比项 | 扩展前 (sobel_04) | 扩展后 (sobel_05) |
| --- | --- | --- |
| 显示模式数 | 4 种 (0~3) | 9 种 (0~8) |
| PL 算法模块 | 1 个 (sobel_core) | 5 个 (+erosion/dilation/mean/sharpen) |
| display_mode 位宽 | 2 bit | 4 bit |
| BRAM 缓存 | 1 个 (edge_mem) | 5 个 |
| SCAN_WAIT 等待 | 仅 edge_frame_done | 全部 5 个 done 信号 |
| MATLAB 验证 | 无 | erode/dilation/mean/sharpen 脚本 |

## MATLAB 软件验证

逐像素对比验证：

| 算法 | Verilog 实现 | MATLAB 对齐方式 |
| --- | --- | --- |
| Sobel | \|Gx\|+\|Gy\|, 边界=0 | imfilter + 边界补 0 |
| 腐蚀 | 3×3 min, 边界=0 | imerode(strel,square,3) + 边界=0 |
| 膨胀 | 3×3 max, 边界=255 | imdilate(strel,square,3) + 边界=255 |
| 均值 | sum×57>>9, 边界=255 | sum9×57/512 (floor), 边界=255 |
| 锐化 | 5×center−neighbors, 钳位 | 5×center−sum(neighbors), 0~255 截断 |

## 问题与总结

问题记录：
1. 控制命令无法设置扩展模式 → PS 端 display_mode = value & 0x03 截断了高位，改为 display_mode = value 支持 0~15
2. SCAN_WAIT 仅等 edge_frame_done → 改为等待全部 5 个 done 信号
3. BRAM 缓存不够 → 新增 erode/dilate/mean/sharpen 共 4 个 mem
4. PC 上位机映射不全 → camera_uart_sender.py 扩展为 9 种

收获：掌握 ZYNQ PS-PL 协同设计流程 (AXI BRAM/UART/HDMI)；理解 5 种图像处理算法的硬件映射 (卷积→行缓存+滑动窗口+流水线)；掌握控制协议设计 (同步头区分数据帧/控制帧)；理解 MATLAB Golden Output 验证方法。

展望：UART 带宽瓶颈 → 升级 Ethernet/USB；支持更高分辨率；增加更多算法 (高斯/Prewitt/Laplacian)；可集成 USB 摄像头直接接入 PS。
